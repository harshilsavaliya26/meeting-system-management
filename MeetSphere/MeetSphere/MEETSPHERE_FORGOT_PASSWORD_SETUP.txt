MeetSphere Forgot Password — setup and test

1. Start MySQL in XAMPP.
2. Open http://localhost/phpmyadmin and select Import.
3. Import database/meetsphere.sql (if your existing database is already in use, run only the CREATE TABLE password_reset_codes statement from that file).
4. Open backend/MeetSphere.Api/appsettings.json. Under Email, set SmtpServer=smtp.gmail.com, Port=587, Username=your Gmail address, AppPassword=your 16-character Google App Password (not your normal Gmail password), FromEmail=the same Gmail address, and FromName=MeetSphere. Do not share or commit the app password.
5. Run the API from backend/MeetSphere.Api:
   dotnet run --urls http://localhost:5001
6. In a second terminal, run the Angular frontend:
   cd frontend
   npm install
   npm start
7. Open http://localhost:4200/login and click Forgot password? or go directly to http://localhost:4200/forgot-password.
8. Enter the email address registered in MeetSphere. Check Inbox and Spam/Junk for the 6-digit code. The code expires after 10 minutes. Resending invalidates the previous code.
9. Enter the code and a new password of at least 8 characters. After success, the page returns to User Login.

Troubleshooting:
- HTTP 503 / SMTP error: check Email settings and create a Google App Password after enabling 2-Step Verification.
- Table error: import/update database/meetsphere.sql; ensure password_reset_codes exists in meetsphere_db.
- Invalid or expired code: request a new code and use the newest email.
- The API uses the registered users table; the email must match a MeetSphere account.
- Keep JWT keys, database credentials, SMTP app passwords and payment secrets private.
